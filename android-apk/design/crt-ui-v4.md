# Reference 566 UI correction — 20 October 2026

Baseline fd7bc09a333865de43906efc986c8e96fdf8e309, PR #654. User evidence: actual APK 591.png versus desired 566.png. This replaces v3 visual decisions on the gameplay surface, not gameplay authority.

## Cause

Earlier work tested the presence of rounded borders, OSD and an animation, but did not compare the composition against the reference at the same pixel dimensions. V3 still used a shiny screwed menu/button style, olive scanline GM background, amber oversized role label and top-aligned log. Its full-height tracking sweep spent part of each cycle outside the image and clipped onto the bezel. Its masked glass asset produced a vertical streak instead of the broad upper-left reflection. Passing functional tests did not establish visual equivalence.

## Implementation

- Compact terminal header with bundled Vietnamese-capable VT323 (unmodified, SIL OFL license included), original camera/signal/battery decoration and a plain dark menu button. Font is local; no network dependency.
- TV retains 1.38 aspect ratio and direct game-grid parent for combat. Uniform CSS optical treatment softens both the correct room background and the character without changing their sources. Broad upper-left glass reflection, vignette/fine scanlines and a broken tracking strip drifting within 70–73 percent of image height replace the old full-screen sweep. Reduced-motion freezes that trace. PLAY uses a filled triangle. OSD clocks remain cosmetic monotonic page-view time, independent of Core/saves/GM.
- New generated nine-slice GM frame with faded hazard tape on both horizontal rails and plain rusted sides; repeated rails preserve proportions. Blue-black panel, subdued role label, cyan turn heading and 14px Play narrative match reference hierarchy. Bottom-align fitting log content with safe overflow fallback; long histories remain scrollable from first to last row. A heading span is presentation-only: original newlines, text, semantic offsets, stored log and player text remain intact.
- Three generated assets (frame, steel button, olive hazard button) are packaged as WebP; transparent margins alone were cropped on buttons. Reference-specific skins apply to gameplay controls, preserving the existing functional menu. The one-time gold rounded PROLOGUE and independent X are retained as explicitly requested earlier. Its visible offer now occupies a temporary row above the TV; read/X consumes it, so continuation has no persistent row. Combat retains snapshot/Dice order.
- Packaging verification now requires the three textures, font and license byte for byte; APK extraction lists include fonts. No provider, Core transaction, save schema, graph, puzzle or Canon changes. GM historical context remains 6,887 characters.
