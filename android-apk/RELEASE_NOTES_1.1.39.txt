Backroom 1.1.39

Character Inventory, Prologue restoration, and Android runtime cleanup release.

- Restores the packaged Prologue and repairs early saves that lost the opening log.
- Adds character-scoped Inventory UI from Party cards. Kai's avatar opens a dedicated Inventory view instead of using a global Inventory panel.
- Kai carries up to 9 normal item stacks with up to x999 per stack. Iris and Syvial use 4 stacks / x20, while ordinary characters use 2 stacks / x2.
- Kai's starting signature gear is Equipment only and no longer consumes normal Inventory capacity.
- Kai Equipment display names are W.W Magnum, Blackblood Armor & linked modules, and Omnivault Ring.
- Save schema v3 migrates older saves by moving Kai's signature gear out of Inventory while preserving normal items.
- Kai's signature equipment and Omnivault remain protected from ordinary Scan/Copy/Transfer/Store paths.
- Omnivault Restore remains narrative-only and direct player pickup remains unavailable as an authoritative gameplay rule.
- Removes retired pickup/Restore reconciliation code from the Android release path.
- Removes base64 Kai overlay reconstruction and packages binary artwork directly.
- Android/Kotlin Game State Core is the authoritative runtime path; LiteRT intent classifier and Gemini fallback remain integrated.
- CI validates the Android build, Kotlin core tests, LiteRT pipeline, Kai avatar packaging, Prologue presence, Equipment/Inventory separation, and absence of retired reconciliation markers.
